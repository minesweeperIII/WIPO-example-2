# Vietnam Creative Industry Employment (2016–2018)

An interactive **R Shiny** web application exploring creative industry employment trends, sector composition, employment types, and working conditions in Vietnam using data from the **Vietnam Labor Force Survey (2016–2018)**.     
**Live App:** https://minesweeperiii.github.io/WIPO-example-2/

---

## Features & Visualizations

Users can switch between four pre-computed visualizations from the dropdown menu:

1. **Creative Industry Share of Total Annual Employment** — Annual share (%) of creative industry workers in Vietnam's employed workforce (2016–2018).
2. **Sector Share of Creative Industry Employment Over Time** 
3. **Average Employment Composition (2016–2018)** — Breakdown of employment status (*Employee*, *Self-employed*, *Owner*, *Family worker*, *Cooperative member*) comparing Creative vs. Non-Creative industries.
4. **Creative vs. Non-Creative Industry Employment: Working Conditions** — Comparison of working conditions (*Average Wage*, *Female Share*, *Permanent Contract*, *Social Insurance*, and *Weekly Hours*).

## Getting Started

### Installation

```r
install.packages(c("tidyverse", "haven", "shiny", "scales", "shinylive", "httpuv"))
```
### Usage    

### 1. Prepare the Data & Pre-build Plots

Download the raw data from [Google Drive](https://drive.google.com/drive/folders/1A2xpsK0lu32MNoDpkkgGWKL39mOp00ds?usp=sharing)     
Place the downloaded files inside `data/`.
Run the following from the project root directory in R locally to generate `data/app_plots.rds`:   

```r
source("prepare_data.R")
```

### 2. Run the App Locally

Test the Shiny application locally in R:

```r
shiny::runApp("app.R")
```

### 3. Build & Preview for GitHub Pages

Export the Shiny app to docs/ as static WebAssembly files:

```r
unlink("docs", recursive = TRUE)
dir.create("_deploy/data", recursive = TRUE)
file.copy("app.R", "_deploy/app.R")
file.copy("data/app_plots.rds", "_deploy/data/app_plots.rds")

shinylive::export(appdir = "_deploy", destdir = "docs")
unlink("_deploy", recursive = TRUE)
```
### 4. Preview static interactive Shiny app locally
```r
httpuv::runStaticServer("docs")
```

## Data Source

* **Vietnam Labor Force Survey 2016–2018** — General Statistics Office of Vietnam (GSO).
* Creative industries are classified using 4-digit **ISIC Rev. 4** codes according to [UNCTAD (2024)](https://unctad.org/system/files/official-document/ditctsce2024d1_en.pdf).
